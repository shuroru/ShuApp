ShuApp プライバシーポリシー

本プライバシーポリシーは、スマートフォン向けアプリケーション「ShuApp」（以下「本アプリ」といいます）における、ユーザーの個人情報の取り扱いについて定めたものです。

1. 取得する情報と利用目的

本アプリでは、サービスの提供および運営のために以下の情報を取得します。

  • Googleアカウント情報（メールアドレス、表示名、アカウント識別ID）：ユーザー認証（ログイン）およびアカウント管理のために利用します。
  • 投稿データ（テキスト、画像）：タイムラインへの表示およびSNS機能の提供のために利用します。
  • 端末識別トークン（FCMトークン）：新着情報やリアクション等のプッシュ通知を送信するために利用します。

2. 情報の管理と第三者提供の禁止

  • 取得したユーザーの個人情報および投稿データは、運営者が管理する専用サーバー内に保存し、不正アクセスや漏洩の防止に努めます。
  • 法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に販売、貸与、または外部へ提供・送信することはありません。

3. 外部サービスの利用

本アプリでは、以下の外部サービスを利用しています。各サービスにおける情報の取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

  • Google Sign-In（Google LLC）：アカウント認証のため
  • Firebase Cloud Messaging（Google LLC）：プッシュ通知配信のため

4. 未成年者（16歳未満）の個人情報について

  • 本アプリは、16歳以上の方を対象として設計されています。運営者は、16歳未満の方から意図的に個人情報を収集することはありません。
  • 万が一、16歳未満の方が本アプリを利用し個人情報を提供していることが判明した場合、運営者は速やかに該当アカウントおよび関連データを削除します。

5. データの削除・退会について

ユーザーは、本アプリ内の機能またはお問い合わせ窓口への連絡により、自身のアカウントおよび投稿データの削除を請求することができます。

6. プライバシーポリシーの変更

運営者は、必要に応じて本プライバシーポリシーを変更することがあります。変更後の内容は、本アプリ内またはWebページ上に掲載した時点で効力を生じるものとします。
